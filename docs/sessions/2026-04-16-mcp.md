# 2026-04-16 — MCP 协议支持（MVP）

## 目标

让 Coco 能连接**任意 MCP server**（stdio 传输），自动发现 server 暴露的工具，把它们当作一等公民工具注入到 agent loop。用户只需在配置文件里加几行声明，就能把 filesystem / git / sqlite / custom MCP server 接入 Coco。

MVP 范围：**stdio 传输 + 仅工具**（不做 resources / prompts / OAuth / HTTP+SSE 传输）。这是 80% MCP server 的使用场景。

---

## 背景与约束

**MCP 是什么**：Model Context Protocol，Anthropic 主导的 JSON-RPC 2.0 协议。server 暴露三类能力——tools / resources / prompts。client 通过协议发现并调用它们。当前官方/社区 server 生态已覆盖 filesystem、git、sqlite、postgres、GitHub、Puppeteer、Slack 等几十个集成。

**为什么对 Coco 有价值**：
1. **零代码扩展工具能力** —— 用户装一个 `mcp-server-filesystem`，Coco 立刻多了 7 个文件系统工具
2. **生态对接** —— 不用 Coco 自己实现每一个集成，直接复用社区 server

**当前状态**（已验证）：
- `src/core/` 下 grep `mcp` 零匹配，`pyproject.toml` 没有 MCP 依赖
- Coco 的 `Tool` 抽象（`tools/base.py`）有清晰的 spec + invoke 协议，非常适合做 adapter

### 关键决策：用官方 `mcp` Python SDK，不自写 JSON-RPC 客户端

手写轻量客户端看似省依赖，实际要处理的协议细节远超 happy path：

- **读写死锁** —— 子进程 stdout 缓冲区满时会阻塞 server 侧的 write，主线程同步 readline 也阻塞，经典死锁
- **notifications 与 responses 交错** —— MCP 允许 server 随时推送 `notifications/*`（`tools/list_changed` 等），不能当无匹配 id 的消息直接丢
- **协议版本协商** —— `protocolVersion` 不匹配时的降级/拒绝逻辑
- **请求取消** —— ESC 中止飞行中 `tools/call` 应发 `notifications/cancelled`
- **schema 校验** —— 响应不符 schema 时的容错策略
- **跨平台 stdio 编码** —— Windows codepage、Unix UTF-8、BOM、行尾
- **优雅关闭顺序** —— terminate → 等 → kill；Windows 没有 SIGTERM 要走 Job Object

每一项都是调试地狱。而官方 `mcp` Python SDK 是 Anthropic 维护、跟着协议演进、这些细节都已处理好的现成品。传递依赖 `pydantic>=2`（Anthropic SDK 已拉入）+ `anyio` + `httpx-sse` 合计 MB 级，**边际成本接近 0**。

另外：未来要扩展 OAuth / HTTP+SSE transport / resources / prompts，官方 SDK 都已实现，自己写的话等于做两遍。

### 其他约束

1. **MCP server 是独立子进程** —— 生命周期要管
2. **工具名可能和 Coco 内置冲突** —— 需要命名空间前缀 `mcp__<server>__<tool>`
3. **MCP 工具全部 `is_read_only=False`**（保守）—— 走权限确认
4. **启动不阻塞** —— 配置 5 个 server，一个慢不能卡 REPL；**懒启动**
5. **不向后传染** —— `mcp` 可选依赖；未装 / 未配置时 Coco 行为完全不变
6. **async → sync 桥** —— 官方 SDK 全异步；Coco `Tool.invoke` 同步。要起一个后台 event loop 跑协程

### Step 2 — async → sync 桥

**新文件 `src/core/mcp/_bridge.py`**（~50 行）：

```python
"""后台线程跑一个永久 event loop，把 async 协程桥成同步调用。

所有 MCP SDK 调用都经这里路由——Coco 其他部分（Engine / Tool）保持同步。
"""

from __future__ import annotations

import asyncio
import threading
from typing import Any, Coroutine, TypeVar

T = TypeVar("T")


class BackgroundLoop:
    """单例式后台 loop。进程退出时 atexit 清理。"""

    def __init__(self) -> None:
        self._loop: asyncio.AbstractEventLoop | None = None
        self._ready = threading.Event()
        self._thread = threading.Thread(
            target=self._run, name="coco-mcp-loop", daemon=True,
        )
        self._thread.start()
        self._ready.wait()

    def _run(self) -> None:
        self._loop = asyncio.new_event_loop()
        asyncio.set_event_loop(self._loop)
        self._ready.set()
        self._loop.run_forever()

    def run(self, coro: Coroutine[Any, Any, T], *, timeout: float | None = None) -> T:
        """同步等待协程完成；超时会向协程发 CancelledError。"""
        assert self._loop is not None
        fut = asyncio.run_coroutine_threadsafe(coro, self._loop)
        return fut.result(timeout=timeout)

    def stop(self) -> None:
        if self._loop and self._loop.is_running():
            self._loop.call_soon_threadsafe(self._loop.stop)
        self._thread.join(timeout=2)
```

`MCPManager` 拥有唯一的 `BackgroundLoop` 实例，注册 `atexit` 清理。

### Step 3 — MCPClient（SDK 薄包装）

**新文件 `src/core/mcp/client.py`**（~120 行）：

```python
"""MCPClient: 用 BackgroundLoop 把 mcp.ClientSession 的 async 接口包成同步调用。

单个实例对应一个已启动的 MCP server 连接。不是线程安全——manager 每个 server 一个实例。
"""

from __future__ import annotations

from contextlib import AsyncExitStack
from dataclasses import dataclass
from typing import Any

from ._bridge import BackgroundLoop
from .config import MCPServerConfig

try:
    from mcp import ClientSession, StdioServerParameters
    from mcp.client.stdio import stdio_client
    _MCP_AVAILABLE = True
except ImportError:
    _MCP_AVAILABLE = False


class MCPClientError(Exception):
    """MCP 客户端侧错误（连接挂了、超时、协议错误等）。"""


@dataclass(frozen=True, slots=True)
class MCPToolMeta:
    name: str
    description: str
    input_schema: dict[str, Any]


_DEFAULT_INIT_TIMEOUT = 15.0
_DEFAULT_CALL_TIMEOUT = 60.0


class MCPClient:
    def __init__(self, loop: BackgroundLoop, config: MCPServerConfig) -> None:
        if not _MCP_AVAILABLE:
            raise MCPClientError(
                "MCP 依赖未安装；请运行 pip install 'coco[mcp]' 或 pip install mcp"
            )
        self._loop = loop
        self._config = config
        self._stack: AsyncExitStack | None = None
        self._session: Any = None
        self._server_name = ""
        self._server_version = ""

    def start(self, timeout: float = _DEFAULT_INIT_TIMEOUT) -> None:
        async def _start() -> None:
            stack = AsyncExitStack()
            try:
                import os
                params = StdioServerParameters(
                    command=self._config.command,
                    args=list(self._config.args),
                    env={**os.environ, **self._config.env} if self._config.env else None,
                )
                read, write = await stack.enter_async_context(stdio_client(params))
                session = await stack.enter_async_context(ClientSession(read, write))
                init_result = await session.initialize()
                self._stack = stack
                self._session = session
                info = getattr(init_result, "serverInfo", None)
                if info is not None:
                    self._server_name = getattr(info, "name", "") or ""
                    self._server_version = getattr(info, "version", "") or ""
            except BaseException:
                await stack.aclose()
                raise

        try:
            self._loop.run(_start(), timeout=timeout)
        except Exception as e:
            raise MCPClientError(f"failed to start {self._config.name!r}: {e}") from e

    def list_tools(self, timeout: float = _DEFAULT_CALL_TIMEOUT) -> list[MCPToolMeta]:
        if self._session is None:
            raise MCPClientError("MCP session not started")

        async def _list() -> Any:
            return await self._session.list_tools()

        try:
            resp = self._loop.run(_list(), timeout=timeout)
        except Exception as e:
            raise MCPClientError(f"list_tools failed: {e}") from e

        tools = getattr(resp, "tools", None) or []
        out: list[MCPToolMeta] = []
        for t in tools:
            name = getattr(t, "name", None)
            if not isinstance(name, str):
                continue
            out.append(MCPToolMeta(
                name=name,
                description=getattr(t, "description", "") or "",
                input_schema=getattr(t, "inputSchema", None)
                    or {"type": "object", "properties": {}},
            ))
        return out

    def call_tool(
        self,
        name: str,
        arguments: dict[str, Any],
        timeout: float = _DEFAULT_CALL_TIMEOUT,
    ) -> tuple[str, bool]:
        """返回 (content_text, is_error)。非 text 块（image/resource）拼接时忽略并标注。"""
        if self._session is None:
            raise MCPClientError("MCP session not started")

        async def _call() -> Any:
            return await self._session.call_tool(name, arguments)

        try:
            result = self._loop.run(_call(), timeout=timeout)
        except Exception as e:
            raise MCPClientError(f"call_tool {name!r} failed: {e}") from e

        parts: list[str] = []
        skipped = 0
        for block in getattr(result, "content", None) or []:
            # SDK 的 TextContent 有 .type == "text" 和 .text 字段
            if getattr(block, "type", "") == "text":
                parts.append(getattr(block, "text", "") or "")
            else:
                skipped += 1
        text = "\n".join(parts).strip() or "(empty)"
        if skipped:
            text += f"\n\n[{skipped} non-text content block(s) omitted]"
        return text, bool(getattr(result, "isError", False))

    def stop(self) -> None:
        if self._stack is None:
            return

        async def _close() -> None:
            await self._stack.aclose()

        try:
            self._loop.run(_close(), timeout=5.0)
        except Exception:
            pass
        finally:
            self._stack = None
            self._session = None

    @property
    def server_display_name(self) -> str:
        return self._server_name or self._config.name
```

**相比手写版本的量级对比**：这个文件 ~120 行，但对比原手写方案的 ~250 行（带 `_request` 循环、`_pump_stderr` 线程、notification 丢弃等），还多省掉了所有协议边界代码——SDK 都接了。

### Step 4 — MCPTool Adapter

**新文件 `src/core/mcp/adapter.py`**：

```python
"""把单个 MCP 工具包装成 Coco Tool。"""

from __future__ import annotations

from typing import Any, Callable

from ..tools.base import Tool, ToolOutcome, ToolSpec
from .client import MCPClient, MCPClientError


class MCPTool(Tool):
    def __init__(
        self,
        *,
        coco_name: str,            # "mcp__fs__read_file"
        server_name: str,          # 配置里的 key，例如 "fs"
        remote_name: str,          # MCP server 侧的原名，例如 "read_file"
        description: str,
        input_schema: dict[str, Any],
        client_provider: Callable[[], MCPClient],
    ):
        self._coco_name = coco_name
        self._server_name = server_name
        self._remote_name = remote_name
        self._description = description
        self._input_schema = input_schema
        self._client_provider = client_provider

    @property
    def spec(self) -> ToolSpec:
        return ToolSpec(
            name=self._coco_name,
            description=f"[MCP:{self._server_name}] {self._description}",
            input_schema=self._input_schema,
            is_read_only=False,   # 保守：MCP 工具都走权限确认
        )

    def invoke(self, arguments: dict[str, Any]) -> ToolOutcome:
        try:
            client = self._client_provider()
        except MCPClientError as e:
            return ToolOutcome(success=False, content=f"Error: MCP server unavailable: {e}", error=str(e))
        try:
            text, is_error = client.call_tool(self._remote_name, arguments)
        except MCPClientError as e:
            return ToolOutcome(success=False, content=f"Error: {e}", error=str(e))
        except Exception as e:
            return ToolOutcome(success=False, content=f"Error: MCP call raised: {e!r}", error=str(e))
        return ToolOutcome(
            success=not is_error,
            content=text,
            error=text if is_error else None,
        )
```

### Step 5 — 配置加载

**新文件 `src/core/mcp/config.py`**：

```python
"""MCP server 配置加载。

路径优先级（低到高）：
  ~/.config/coco/mcp_servers.toml   — 全局
  <workspace>/.coco/mcp_servers.toml — 项目级

格式示例：

    [fs]
    command = "npx"
    args = ["-y", "@modelcontextprotocol/server-filesystem", "/path/to/ws"]
    env = { DEBUG = "1" }

    [git]
    command = "uvx"
    args = ["mcp-server-git"]
"""

from __future__ import annotations

import sys
from dataclasses import dataclass, field
from pathlib import Path

if sys.version_info >= (3, 11):
    import tomllib
else:
    try:
        import tomllib  # type: ignore
    except ModuleNotFoundError:
        import tomli as tomllib  # type: ignore

from ..paths import config_home


@dataclass(frozen=True, slots=True)
class MCPServerConfig:
    name: str
    command: str
    args: tuple[str, ...] = ()
    env: dict[str, str] = field(default_factory=dict)


def _read_file(path: Path) -> dict:
    if not path.is_file():
        return {}
    try:
        with path.open("rb") as f:
            return tomllib.load(f) or {}
    except Exception:
        return {}


def load_mcp_configs(workspace: Path | None = None) -> list[MCPServerConfig]:
    merged: dict[str, dict] = {}
    merged.update(_read_file(config_home() / "mcp_servers.toml"))
    if workspace is not None:
        merged.update(_read_file(workspace / ".coco" / "mcp_servers.toml"))

    out: list[MCPServerConfig] = []
    for name, entry in merged.items():
        if not isinstance(entry, dict):
            continue
        command = entry.get("command")
        if not isinstance(command, str) or not command:
            continue
        args_raw = entry.get("args") or []
        env_raw = entry.get("env") or {}
        out.append(MCPServerConfig(
            name=name,
            command=command,
            args=tuple(str(a) for a in args_raw if isinstance(a, (str, int, float))),
            env={str(k): str(v) for k, v in env_raw.items()} if isinstance(env_raw, dict) else {},
        ))
    return out
```

### Step 6 — MCPManager

**新文件 `src/core/mcp/manager.py`**：

```python
"""多 MCP server 管理：懒启动、按需列 tools、失败隔离、atexit 清理。"""

from __future__ import annotations

import atexit
import threading
from typing import Any

from .. import log
from ..tools.base import Tool
from ._bridge import BackgroundLoop
from .adapter import MCPTool
from .client import MCPClient, MCPClientError
from .config import MCPServerConfig


class MCPManager:
    def __init__(self, configs: list[MCPServerConfig]) -> None:
        self._configs = {c.name: c for c in configs}
        self._loop = BackgroundLoop()
        self._clients: dict[str, MCPClient] = {}
        self._failed: set[str] = set()
        self._lock = threading.Lock()
        atexit.register(self.shutdown_all)

    def _get_client(self, server_name: str) -> MCPClient:
        with self._lock:
            if server_name in self._failed:
                raise MCPClientError(f"server {server_name!r} previously failed to start")
            client = self._clients.get(server_name)
            if client is None:
                cfg = self._configs.get(server_name)
                if cfg is None:
                    raise MCPClientError(f"unknown server {server_name!r}")
                client = MCPClient(self._loop, cfg)
                try:
                    client.start()
                except MCPClientError:
                    self._failed.add(server_name)
                    raise
                self._clients[server_name] = client
            return client

    def discover_tools(self) -> list[Tool]:
        """启动所有 server 并收集 tools。单 server 失败不影响其他。"""
        tools: list[Tool] = []
        for name in self._configs:
            try:
                client = self._get_client(name)
                metas = client.list_tools()
            except MCPClientError as e:
                log.warn(f"MCP server {name!r} 不可用：{e}")
                continue
            for meta in metas:
                coco_name = f"mcp__{name}__{meta.name}"
                tools.append(MCPTool(
                    coco_name=coco_name,
                    server_name=name,
                    remote_name=meta.name,
                    description=meta.description,
                    input_schema=meta.input_schema,
                    client_provider=(lambda n=name: self._get_client(n)),
                ))
            log.dim(f"  · MCP [{name}] 注册了 {len(metas)} 个工具")
        return tools

    def list_server_status(self) -> list[tuple[str, str, int]]:
        """(server_name, status, tool_count) —— 给 /mcp 命令用。"""
        out: list[tuple[str, str, int]] = []
        for name in self._configs:
            if name in self._failed:
                out.append((name, "failed", 0))
            elif name in self._clients:
                try:
                    count = len(self._clients[name].list_tools())
                except Exception:
                    count = -1
                out.append((name, "running", count))
            else:
                out.append((name, "idle", -1))
        return out

    def shutdown_all(self) -> None:
        with self._lock:
            for client in self._clients.values():
                try:
                    client.stop()
                except Exception:
                    pass
            self._clients.clear()
        try:
            self._loop.stop()
        except Exception:
            pass
```

```markdown
## 配置

在 `~/.config/coco/mcp_servers.toml` 或项目下 `.coco/mcp_servers.toml`：

    args = ["mcp-server-git"]

Coco 启动时会懒启动这些 server，把它们暴露的工具注册为
`mcp__fs__*` / `mcp__git__*`（带命名空间前缀避免冲突）。

## 注意

- MCP 工具默认需要权限确认（与 Write/Edit 同级）
- 某个 server 启动失败不影响其他 server 或 Coco 本身
- 用 `/mcp` 查看状态，`/doctor` 做诊断
```

---

## 不做的事

- ❌ **OAuth 流程** —— 只支持不需要认证的 server 或通过 env var 传 API key 的 server
- ❌ **HTTP+SSE 传输** —— 只做 stdio
- ❌ **Resources 与 Prompts** —— 只做 tools
- ❌ **动态 reconnect** —— server 挂了就 `failed`；用户看 `/mcp` 自己手动重启
- ❌ **并发 server 启动** —— 顺序启动，一个不返回就等超时
- ❌ **把 MCP 工具做 `is_concurrency_safe`** —— 默认串行，保守安全
- ❌ **自动发现 server**（扫 npm / pypi）—— 用户显式配置
